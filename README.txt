駅ダッシュボード（PWA）

【公開のしかた：GitHub Pages（無料）】
1. GitHubでアカウントを作り、新しいリポジトリ（Public）を作る
2. このフォルダの中身をすべてアップロードする（index.html が一番上の階層に来るように）
3. Settings > Pages で、Branch を main / (root) にして Save
4. 数分後に https://（ユーザー名）.github.io/（リポジトリ名）/ で開ける

【iPhoneに入れる】
1. 上のURLを Safari で開く（Chromeではなく Safari）
2. 共有ボタン > 「ホーム画面に追加」
3. ホーム画面のアイコンから起動する

※ 位置情報（現在地の駅）は HTTPS の公開URLでのみ動きます。
